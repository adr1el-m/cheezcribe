## 💡 The Problem: Digitized ≠ Understood

> *"What happens when decades of critical municipal, engineering, and institutional knowledge remain trapped in fading paper?"*

Across utility departments, historical archives, public works boards, and engineering firms, billions of irreplaceable physical documents are silently decaying:
- **Hand-drafted architectural blueprints** with uncalibrated dimensions and obscured piping runs.
- **Century-old civil infrastructure plans** vital for modern maintenance and disaster resilience.
- **Municipal gazetteers, registries, and technical logs** with faded typography, stamps, and handwritten annotations.

### The Conventional Flaw

Standard scanning equipment and consumer OCR tools produce **flat, dead pixels**:
1. **Trapped Information**: A 300 DPI PDF is an image of text, not actionable database records or editable CAD geometry.
2. **CAD Blindness**: No generic scanner can distinguish between a title block, a structural column, an intake pipe, or a foundation ring.
3. **Hallucination Risk**: Modern LLMs fed noisy OCR often hallucinate missing numbers, dates, or specifications with zero traceability back to the source paper.

## ✨ What is Paperazzi?

**Paperazzi** bridges the chasm between paper history and modern engineering workflows. It is an end-to-end legacy document intelligence system built in **Flutter**, powered by **On-Device Apple Vision / ML Kit** and resilient **Edge Multimodal Vision AI**.

Unlike passive scanners, Paperazzi:
- 👁️ **Sees**: Applies adaptive local contrast enhancement and neural OCR to extract faded, low-contrast text on-device.
- 🧠 **Understands**: Segregates tabular rows, entity metadata, and engineering figures.
- 📐 **Vectorizes**: Converts architectural blueprints directly into **CAD DXF** and **SVG** geometry with interactive real-world scale calibration.
- 🔍 **Verifies**: Never presents unchecked AI guesses. Every single extracted entity is linked to its exact visual source crop with side-by-side verification and audit history.

## 🔄 The 4-Step Intelligent Pipeline

Paperazzi executes a disciplined four-stage pipeline designed for mission-critical accuracy:

<p align="center">
  <img src="readme_images/pipeline_workflow.png" width="95%" alt="How Paperazzi Works" style="border-radius: 10px;" />
</p>

| Stage | What Happens Under the Hood | User Experience |
|:---|:---|:---|
| **01. Capture** | Invokes live device camera (`getUserMedia` on Web, `AVFoundation` on iOS, `Camera2` on Android) with multi-frame edge detection, auto-crop, perspective rectification, and contrast normalization. | Clean, glare-reduced, perspective-corrected document image retained as the immutable ground truth. |
| **02. Understand** | Runs fast on-device neural OCR (98+ lines/sec) coupled with structured entity extraction and drawing contour detection. | Instant detection of document type, project metadata, tabular entries, and geometric shapes. |
| **03. Verify** | Computes confidence scores, flags OCR/AI disagreements, and isolates exact source image bounding boxes (`PAGE • ZONE • LINE`). | Interactive **Human-in-the-Loop** verification queue. Users confirm, edit, or reject values with 1-tap review. |
| **04. Transform** | Translates structured entities into tabular records and compiles detected contours into scaled CAD vector layers. | One-tap export to **CAD DXF**, **Vector SVG**, **Field Ledger CSV**, **Records CSV**, **JSON**, and **PDF Summary**. |

## 📐 Signature Feature 1: Blueprint to CAD Vectorization

> *"A blueprint doesn't have to stay a picture."*

Paperazzi is the first mobile archive tool that converts physical engineering blueprints into editable CAD vectors without leaving your phone or browser.

<p align="center">
  <img src="readme_images/blueprint_to_cad.png" width="95%" alt="From Blueprint to CAD" style="border-radius: 10px;" />
</p>

### How Drawing Intelligence Works

1. **Semantic Engineering Detection**: Distinguishes structural elements from background grid lines and annotations (e.g., *tank sections, foundation slabs, central risers, roof outer rings, radial roof supports, supply/waste pipelines, valve assemblies*).
2. **Interactive Scale Calibration**: Blueprints often have distorted reproduction ratios. Paperazzi allows the engineer to tap any detected element (e.g., a known 3-inch intake or 860-meter pipeline) and enter its real-world dimension. All vector coordinates are automatically normalized to that calibrated unit.
3. **Universal CAD Export**:
   - **AutoCAD DXF**: Ready to import into AutoCAD, SolidWorks, Revit, or FreeCAD as native vector entities.
   - **Scalable Vector Graphics (SVG)**: Crisp vector illustrations for web documentation, GIS layers, and vector renderers.

## 🛡️ Signature Feature 2: Human-in-the-Loop Provenance

> *"AI makes the first pass. Humans make the final call."*

Hallucinations are unacceptable in civil records, building schematics, or legal archives. Paperazzi implements an uncompromising **Zero-Hallucination Architecture**.

<p align="center">
  <img src="readme_images/human_in_the_loop.png" width="95%" alt="Trust and Human in the Loop" style="border-radius: 10px;" />
</p>

### 100% Traceable Evidence

- **Pixel-Level Provenance**: Every extracted field links directly to its parent document, page number, vertical line index, and exact image crop.
- **Disagreement Routing**: When on-device OCR and cloud AI return conflicting readings, Paperazzi never averages or conceals them. It marks the field as `Needs verification`, routes it to the top of the **Review Queue**, and displays both candidates alongside the zoomed source crop.
- **Audit Change Log**: Every decision (*Confirm*, *Edit*, *Keep OCR*, *Mark unreadable*) is logged with timestamps, reviewer decisions, and provenance data in the exported audit JSON.

## ⚡ Signature Feature 3: Hybrid On-Device & Edge AI

Paperazzi delivers a privacy-first, ultra-resilient architecture combining local on-device inference with multi-tier cloud fallback:

```mermaid
flowchart TD
    subgraph Client ["Client Device (iOS • Android • Web)"]
        A["Document Capture (Camera / File)"] --> B["Image Enhancement (Contrast & De-skew)"]
        B --> C{"Platform Check"}
        C -->|"iOS / Android"| D["On-Device Neural OCR (Apple Vision / ML Kit)"]
        C -->|"Web Browser"| E["Canvas Snapshot (High-Res JPEG)"]
        D --> F["Local Geometry & Table Parsing"]
    end

    subgraph Cloud ["Secure Edge Infrastructure (Vercel Serverless)"]
        E --> G["POST /api/analyze"]
        G --> H{"Provider Waterfall"}
        H -->|"Primary"| I["Groq Vision (Qwen 3.8 / Llama 4)"]
        H -->|"Secondary"| J["Google Gemini (2.5 Pro / 3.8 Flash)"]
        H -->|"Fallback"| K["Mistral AI (Large Multimodal)"]
    end

    subgraph Verification ["Human-in-the-Loop Engine"]
        F --> L["Field Conflict & Confidence Validator"]
        I --> L
        J --> L
        K --> L
        L --> M["Interactive Verification Queue"]
        M --> N["Immutable Change Log & Checkpoint"]
    end

    subgraph Output ["Asset Transformation"]
        N --> O["CAD DXF (AutoCAD)"]
        N --> P["Vector SVG"]
        N --> Q["Structured JSON & CSV"]
        N --> R["Archival Audit PDF"]
    end
```

### Why This Hybrid Architecture Wins

1. **Zero Data Leakage for Classified Documents**: On native iOS and Android, all OCR, table parsing, drawing vectorization, and checkpoint storage can run **100% offline on-device**. No cloud key required.
2. **Instant Web Availability for Public Visitors**: The web app runs without downloading gigabytes of models. It delegates image understanding to a secure edge proxy with a **75-second timeout** and multi-provider redundancy.
3. **Resilient Provider Cascade**: If Groq rate-limits or cold-starts, Gemini immediately picks up the payload. If Gemini fails, Mistral engages. The user never sees a broken screen.

## 🏗️ Technical Architecture & Stack

### Frontend & Core Application
- **Framework**: [Flutter 3.x](https://flutter.dev) (Dart 3.x) targeting **iOS**, **Android**, and **Web**.
- **Native iOS Engine**: Swift / Objective-C bridging with `Apple Vision` (`VNRecognizeTextRequest`, `VNDetectRectanglesRequest`) and `CoreGraphics`.
- **Native Android Engine**: Kotlin with Google `ML Kit Text Recognition` and `Camera2`.
- **Web Engine**: Flutter Web compiled to optimized CanvasKit JS with direct `html.window.navigator.mediaDevices.getUserMedia` hardware integration.

### Edge Backend & Vision Proxy
- **Runtime**: Node.js 24 Serverless Functions deployed on [Vercel](https://vercel.com).
- **Vision AI Inference**:
  - **Groq Cloud**: Ultra-low-latency `qwen/qwen3.8-27b` and `meta-llama/llama-4-scout-17b-16e-instruct`.
  - **Google Gemini**: Multimodal `gemini-2.5-pro` and `gemini-3.8-flash`.
  - **Mistral AI**: Fallback `mistral-large-latest`.
- **Web Landing Page**: [Vite](https://vitejs.dev) + [React 19](https://react.dev) with responsive interactive device showcase and dynamic preview modals.

### Repository Layout


## 🚀 Quick Start & Installation

### Option 1: Try Instantly in Your Browser (No Installation)

Open **[https://paperazzi-appcon.vercel.app/app/](https://paperazzi-appcon.vercel.app/app/)** on any phone, tablet, or desktop browser:
1. Tap **Scan Document** to open your live camera and capture any physical sheet.
2. Or tap **Load Tagbilaran 1915 demo file** to explore the pre-loaded municipal waterworks blueprint demo.
3. Review extracted entities, calibrate drawing scale, and export CAD files directly!

---

### Option 2: Run Locally (Flutter iOS / Android / Web)

#### Prerequisites
- [Flutter SDK 3.29+](https://docs.flutter.dev/get-started/install)
- Xcode 15+ (for iOS Simulator or physical iPhone)
- Android Studio / SDK (for Android emulator or physical device)
- Node.js 20+ (for edge proxy and landing page)

```bash
# 1. Clone the repository
git clone https://github.com/adr1el-m/cheezcribe.git
cd cheezcribe

# 2. Run automated test suite
cd app
flutter test test/legacy_validation_test.dart test/widget_test.dart

# 3. Launch on iOS Simulator
flutter run -d iPhone

# 4. Or launch in Chrome for Web
flutter run -d chrome
```

#### Running the Vercel Edge API Locally

```bash
# In project root
vercel dev
```
