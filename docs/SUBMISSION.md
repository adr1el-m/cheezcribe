# Submission checklist

Official requirements derive from supplied PDF pages 5 and 7. Recommended engineering checks are labeled separately.

## Official

- [ ] Entry directly addresses the drawn sub-theme and uses AI as core technology.
- [ ] Public Git repository accessible while logged out.
- [ ] README includes overview and complete setup instructions.
- [ ] Genuine commits show development during the hackathon.
- [ ] MIT LICENSE present with correct holder.
- [ ] Code, documentation and related materials publicly accessible.
- [ ] Third-party dependencies attributed and licenses respected.
- [ ] Proprietary APIs/datasets/services documented, with access or substitution instructions.
- [ ] Core functionality accessible to the public with documented setup.
- [ ] Fully functional working prototype/product demonstration.
- [ ] Presentation includes problem, solution, AI, architecture and potential impact.
- [ ] All repository links/materials submitted through announced process/Team Portal before exact cutoff.

## Recommended release checks

- [ ] Replace all team, member, theme and model fields with accurate values.
- [ ] Fresh setup reproduced by a second member.
- [ ] `dart format`, `flutter analyze`, meaningful tests and Android build pass.
- [ ] Release APK installed and real AI succeeds on the demo phone.
- [ ] App Check release attestation tested independently from emulator debug access.
- [ ] Empty input, slow network, no network, quota failure, unsafe output and retry tested.
- [ ] Saved input survives errors; no duplicate action on retry.
- [ ] No private credentials, App Check debug tokens, personal documents or signing keys in tracked files/history.
- [ ] Evaluation data states which cases are synthetic; results contain no fabricated users/statistics.
- [ ] Deck uses actual screenshots and evidence; limitations stated.
- [ ] Demo backup is accurately labeled and plays locally.
- [ ] Links/download permissions tested while logged out.
- [ ] Leader retains final portal receipt and checks every upload opens.
