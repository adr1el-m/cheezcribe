## Adaptable directions

| Only if relevant to drawn theme | Possible AI-centered workflow | Useful demonstration evidence |
|---|---|---|
| Public service access | Explain a notice/form using an approved reference; return required next steps with source excerpts | Steps recovered correctly; unsupported requirements rejected |
| Accessibility | Convert complex text into an easy-read checklist, preserving facts and original context | Task comprehension compared with original text |
| Education | Diagnose a learner's misconception and choose a targeted worked example | Correct concept diagnosis and improvement on follow-up task |
| Environment | Interpret a waste/material description against verified local guidance | Classification correctness; uncertain materials flagged |
| Livelihood | Convert a seller's task constraints into a checkable plan using supplied facts | Constraint satisfaction and time saved |

Do not invent local ordinances, service eligibility, medical advice or official procedures. If authoritative data is unavailable, choose a task whose output can be checked against the supplied input rather than claiming external truth.
